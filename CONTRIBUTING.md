# Contributing

Contributions are welcome. Please open an issue first for changes to scientific scope or data interpretation.

## Development

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

Keep source attribution with every external record. Do not add API keys, private credentials, copied copyrighted text, or inferred genetic measurements. Add interface text to both `src/i18n/es/common.json` and `src/i18n/en/common.json`.
